xml.etree.ElementTree → XML read/write
hashlib               → encrypt password


Login Flow (How it works)

User enters username + password
        ↓
PyQt6 UI sends data to auth_service
        ↓
auth_service reads users.xml
        ↓
check username & password
        ↓
if match → Login success
else → Invalid credentials



Register (Create New User)

User clicks Register
        ↓
Enter username + password
        ↓
Check if username already exists in XML
        ↓
If not exist → append to XML
        ↓
Save users.xml
